### 🚀 Local Setup & Installation Guide

Follow these step-by-step instructions to set up and run this project locally:

#### 1. Prerequisites
*   Download and install **Node.js** (LTS version recommended) on your machine.

#### 2. Project Initialization
Create a project folder and initialize it with a `package.json` file:
```bash
# Create a new project folder
mkdir CypressAutomation

# Navigate into the project folder
cd CypressAutomation

# Generate a default package.json file
npm init -y
```

#### 3. Install Cypress Dependencies
Install Cypress as a dev-dependency. This will automatically generate the `node_modules` folder containing all necessary libraries:
```bash
# Install Cypress locally
npm install cypress --save-dev

# (Alternative) Install all project dependencies defined in package.json
npm install
```

#### 4. Open Cypress Test Runner
Execute the local binary command to launch the interactive Cypress GUI interface:
```bash
# Open the Cypress Test Runner
./node_modules/.bin/cypress open
```
